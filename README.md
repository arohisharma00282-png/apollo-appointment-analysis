# Apollo Hospitals - Appointment No-Show Analysis

EDA project analyzing 75,000 appointments to understand no-show patterns, 
reminder effectiveness, revenue impact, and doctor utilisation.

## Key Findings
- Overall no-show rate: 15.9%
- Revenue lost to no-shows: ₹1.97 Cr (21% of potential revenue)
- Reminders cut no-show rate from 30.2% to 11.4%
- Longer booking lead time increases no-show risk

## Tools
Python, Pandas, Matplotlib, Seaborn
